## 口袋句庫 Pocketbrief v4.3.0

### 🍎 新增 Mac 版

口袋句庫現在也有 macOS 版了，功能與 Windows 版相同：叫出清單、打代碼輸出、反白快速新增、句庫管理、10 種配色、深色模式、四種介面語言。

**Mac 版和 Windows 版共用同一份 `範本.csv`**：把句庫資料夾放在雲端硬碟，兩邊改的範本都會同步。

### ⌨️ Windows 版更新

- 快速鍵可以設成「按住 `` ` `` 再按一個鍵」（例如 `` ` `` + `1`），左手動作更小。
- 修正：按住快速鍵稍久一點時，數字會被打進清單。
- 修正：清單在少數情況下沒搶到鍵盤焦點時，打的代碼會跑進原本的文件；現在會改用備援方式取得焦點，取不到就自動收起清單。

### 下載

| 檔案 | 適用 |
|---|---|
| `Pocketbrief-v4.3.0-windows.zip` | Windows 10／11：解壓縮後執行 `Pocketbrief.exe` |
| `Pocketbrief-v4.3.0-mac.zip` | macOS 13 以後（Apple 晶片與 Intel）：解壓縮後把 `Pocketbrief.app` 拖進「應用程式」 |

**Mac 版第一次打開**：因為沒有付費的 Apple 開發者簽章，macOS 會擋下來。
- macOS 15 以後：先打開一次，再到「系統設定」→「隱私權與安全性」按「強制打開」。
- macOS 13、14：在 app 上按右鍵 →「打開」。

接著依提示選擇句庫資料夾，並開啟「輔助使用」權限。詳細步驟請看 [README](https://github.com/ulysses5976/Pocketbrief#mac-版)。

**Windows 版**第一次執行時 SmartScreen 可能提醒，請按「其他資訊」→「仍要執行」。

## Pocketbrief v4.3.0

### 🍎 New: Mac version

Pocketbrief now runs on macOS too, with the same features as on Windows: the pop-up list, codes, quick add, the Phrase Library, 10 color themes, dark mode and four UI languages.

**The Mac and Windows versions share the same `範本.csv`**: keep the library folder in a cloud drive and templates stay in sync on both.

### ⌨️ Windows updates

- Hotkeys can be set as "hold `` ` `` and press a key" (e.g. `` ` `` + `1`) for a smaller left-hand move.
- Fixed: holding the hotkey a little longer typed digits into the list.
- Fixed: in rare cases when the list didn't get keyboard focus, typed codes went into the original document. Pocketbrief now tries a fallback, and closes the list if it still can't get focus.

### Download

| File | For |
|---|---|
| `Pocketbrief-v4.3.0-windows.zip` | Windows 10/11: unzip and run `Pocketbrief.exe` |
| `Pocketbrief-v4.3.0-mac.zip` | macOS 13 or later (Apple silicon and Intel): unzip and drag `Pocketbrief.app` into Applications |

**Opening the Mac version the first time**: it has no paid Apple Developer signature, so macOS blocks it at first.
- macOS 15 or later: open it once, then click **Open Anyway** in System Settings → Privacy & Security.
- macOS 13 or 14: right-click the app → **Open**.

Then choose a library folder and turn on the Accessibility permission when asked. See the [README](https://github.com/ulysses5976/Pocketbrief/blob/main/README.en.md#mac) for details.

**On Windows**, SmartScreen may warn you on first run: click **More info → Run anyway**.
