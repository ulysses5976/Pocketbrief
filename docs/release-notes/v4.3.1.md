## 口袋句庫 Pocketbrief v4.3.1

這一版只改了下載檔的內容，程式功能和 v4.3.0 相同。**已經在用 v4.3.0 的人不需要更新。**

### 📦 改了什麼

- Mac 版的 zip 現在也附上授權聲明（LICENSE）、說明文件和 `examples/` 範例句庫，和 Windows 版一致。
- 說明文件修正：自動備份是「保留最近 14 份」，不是 14 天。

### 下載

| 檔案 | 適用 |
|---|---|
| `Pocketbrief-v4.3.1-windows.zip` | Windows 10／11：解壓縮後執行 `Pocketbrief.exe` |
| `Pocketbrief-v4.3.1-mac.zip` | macOS 13 以後（Apple 晶片與 Intel）：解壓縮後把 `Pocketbrief.app` 拖進「應用程式」 |

**Mac 版第一次打開**：因為沒有付費的 Apple 開發者簽章，macOS 會擋下來。
- macOS 15 以後：先打開一次，再到「系統設定」→「隱私權與安全性」按「強制打開」。
- macOS 13、14：在 app 上按右鍵 →「打開」。

接著依提示選擇句庫資料夾，並開啟「輔助使用」權限。**從舊版換成新版後，要到「輔助使用」把 Pocketbrief 移除再重新加入**，否則快速鍵會沒反應。詳細步驟請看 [README](https://github.com/ulysses5976/Pocketbrief#mac-版)。

**Windows 版**第一次執行時 SmartScreen 可能提醒，請按「其他資訊」→「仍要執行」。

## Pocketbrief v4.3.1

This release only changes what's in the downloads; the app works the same as v4.3.0. **If you already use v4.3.0, you don't need to update.**

### 📦 What changed

- The Mac zip now includes the license (LICENSE), the READMEs and the `examples/` sample libraries, like the Windows zip.
- Docs fix: automatic backups keep the 14 most recent copies, not 14 days.

### Download

| File | For |
|---|---|
| `Pocketbrief-v4.3.1-windows.zip` | Windows 10/11: unzip and run `Pocketbrief.exe` |
| `Pocketbrief-v4.3.1-mac.zip` | macOS 13 or later (Apple silicon and Intel): unzip and drag `Pocketbrief.app` into Applications |

**Opening the Mac version the first time**: it has no paid Apple Developer signature, so macOS blocks it at first.
- macOS 15 or later: open it once, then click **Open Anyway** in System Settings → Privacy & Security.
- macOS 13 or 14: right-click the app → **Open**.

Then choose a library folder and turn on the Accessibility permission when asked. **After replacing an older version, remove Pocketbrief from Accessibility and add it again**, or the hotkey won't respond. See the [README](https://github.com/ulysses5976/Pocketbrief/blob/main/README.en.md#mac) for details.

**On Windows**, SmartScreen may warn you on first run: click **More info → Run anyway**.
