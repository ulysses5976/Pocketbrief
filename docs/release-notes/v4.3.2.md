## 口袋句庫 Pocketbrief v4.3.2（Windows 版）

這一版只更新 **Windows 版**，修正三個問題。Mac 版沒有變動，仍是 v4.3.1（本頁附的 Mac 檔案就是 v4.3.1 那一份）。

### 🛠 修正

- **輸出範本後，原本複製的中文貼出來變亂碼**：從網頁、Word、Outlook 複製的內容，在輸出範本後再按 Ctrl+V，中文會變成亂碼。現在會原封不動地暫存並放回剪貼簿。
- **輸出範本後馬上按 Ctrl+V，貼出的卻是範本**：以前要等約 1 秒，原本複製的內容才會回到剪貼簿。現在範本一貼上就會放回；在放回之前按 Ctrl+V（或 Shift+Insert），也會先放回原本的內容再貼上。
- **用「` + 1」這類快速鍵，有時按了沒有跳出清單**：修正叫出清單時搶不到焦點、清單一出現就被收起來的問題。

### 下載

| 檔案 | 適用 |
|---|---|
| `Pocketbrief-v4.3.2-windows.zip` | Windows 10／11：解壓縮後執行 `Pocketbrief.exe` |
| `Pocketbrief-v4.3.1-mac.zip` | macOS 13 以後（Apple 晶片與 Intel）：與 v4.3.1 相同 |

**從舊版更新（Windows）**：先在系統匣圖示按右鍵結束口袋句庫，再用新的 `Pocketbrief.exe` 覆蓋舊檔即可。範本與設定都不受影響。

第一次執行時 SmartScreen 可能提醒，請按「其他資訊」→「仍要執行」。Mac 版的安裝方式請看 [README](https://github.com/ulysses5976/Pocketbrief#mac-版)。

## Pocketbrief v4.3.2 (Windows)

This release updates the **Windows version** only, with three fixes. The Mac version is unchanged and stays at v4.3.1 (the Mac file on this page is the same v4.3.1 download).

### 🛠 Fixes

- **Copied text turned into garbled characters after inserting a template**: after inserting a template, pressing Ctrl+V to paste something copied from a web page, Word or Outlook could produce garbled non-English text (such as Chinese). The clipboard is now saved and put back exactly as it was.
- **Pressing Ctrl+V right after inserting a template pasted the template again**: your copied content used to come back to the clipboard only after about a second. Now it's put back as soon as the template has been pasted, and if you press Ctrl+V (or Shift+Insert) before that, Pocketbrief puts your content back first and then pastes.
- **A hotkey like `` ` `` + `1` sometimes didn't open the list**: fixed the list closing itself right away when it didn't get keyboard focus at first.

### Download

| File | For |
|---|---|
| `Pocketbrief-v4.3.2-windows.zip` | Windows 10/11: unzip and run `Pocketbrief.exe` |
| `Pocketbrief-v4.3.1-mac.zip` | macOS 13 or later (Apple silicon and Intel): same as v4.3.1 |

**Updating on Windows**: right-click the tray icon to quit Pocketbrief, then replace the old `Pocketbrief.exe` with the new one. Your templates and settings are kept.

On first run, SmartScreen may warn you: click **More info → Run anyway**. For installing the Mac version, see the [README](https://github.com/ulysses5976/Pocketbrief/blob/main/README.en.md#mac).
